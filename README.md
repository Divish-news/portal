Included files:

- style.css

How to publish on GitHub Pages:
1. Download and unzip portfolio_updated.zip.
2. Open your portfolio repository on GitHub.
3. Replace the existing index.html, style.css, and script.js with these versions.
4. Commit the changes to the branch/folder used by GitHub Pages.
5. Wait a few minutes, then refresh the website. If the old CSS/JS still appears, do a hard refresh or clear the browser cache.

Before publishing, verify that the profile image URL and all personal details are correct.

Notes:
- The language selector translates text marked for English/Kinyarwanda; not every technical term is translated.
- Theme and language preferences are saved in the browser when local storage is available.
- Project cards marked “In development” are clearly not presented as live services.
- Certificate cards show a pending-link icon until you add real verification URLs.
- The utility-reporting concept does not send reports to WASAC or REG; an appropriate backend and authorized integration would be required.
